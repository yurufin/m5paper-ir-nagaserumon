# ir-timer

記録した赤外線信号を決まった時刻に送る。M5Paper + IR Unit (U002, PORT.B)。
画面の文言は流せるもん(CWA-67B)の自動洗浄用だが、信号を差し替えれば他の赤外線機器にも使える。
信号は `ir-register` で採用した SD の `/ir/flush.txt` を読む(同じ SD を挿したまま使う)。

## 書き込み

```
cd ir-timer
pio run -t upload --upload-port COMx
```

## 動作

- **自動**: 既定は 00:00 / 06:00 / 12:00 / 18:00。SD の `/ir/schedule.txt` に `HH:MM` を 1 行ずつ書けば差し替え(再起動で反映)
- **手動**: 画面の「今すぐ流す」ボタン、または押込ボタン(G38)。いつでも送る(15 分ガードなし、二度押し防止の 3 秒だけ)

## 画面

縦向き・天地逆(USB 端子が上、`DISPLAY_ROTATION = 2`)。上から

- 黒帯: 電池残量、Wi-Fi(最後の時刻合わせが成功していれば表示)
- タイトル、日付、時刻(毎分更新)
- 「今すぐ流す」ボタン
- 枠: 自動洗浄時刻(次の予定を角丸で囲む)、最終洗浄時刻(自動/手動)、結果の黒帯(`MANUAL FLUSH OK` / `AUTO FLUSH OK`。信号ファイルが無い・時刻未設定のときはその警告)

1 ビットのキャンバスに描き、毎分は黒帯と日付・時刻の範囲だけ書き換える。1 時間ごとと次の予定が変わったときは全面をきれいに書き直す。

文字は `tools/gen_fonts.ps1` が Windows の TTF(既定は Noto Sans JP Bold)から作る 1 ビットのビットマップ(`src/ui_fonts.h`)。
入る文字は `tools/gen_fonts.cs` に並べたものだけなので、画面の文言を変えたらそこに足して作り直す。

```
powershell -ExecutionPolicy Bypass -File tools\gen_fonts.ps1
```

シリアルで `S` を送ると、画面の中身を PBM(P4, 540x960)で返す(見た目の確認用)。

## 時刻

- 内蔵 RTC(BM8563)に日本時間をそのまま入れて使う
- SD の `/ssid.txt`(1 行 `SSID,PASSWORD`、複数行なら上から順に試す)があれば、起動時と 24 時間ごとに NTP(ntp.nict.jp)で合わせる。それ以外は Wi-Fi を切っている
- RTC が 2025 年より前(未設定)なら自動送信はしない。手動は送る

## 安全設計

- 自動送信は前回の自動送信から 15 分以内なら送らない(手動は対象外)
- 予定時刻ごとに「済み」を NVS に残すので、再起動しても同じ枠で二度は送らない
- 停電などで予定時刻を過ぎて起動した場合、30 分以内なら送る。それより遅ければ送らずログに残す
- 初めて起動したときは、直前の予定時刻の分はすぐには送らない

## 記録

- NVS(電源断で消えない): 累計回数、最終実行時刻と種別、最後の自動送信時刻、最後に処理した予定時刻
- SD の `/ir/log.txt`: `2026/11/24 12:00,auto,ok` のように 1 行ずつ(スキップした理由も残る)

## 電源

タッチでいつでも流せるよう常時起動にしている(電源は落とさない)ため、**USB 給電が前提**。
電池だけでは 1 日程度しかもたない見込み。

## 送信

RMT で 1µs 単位、38kHz・デューティ 33% のキャリアをかけて `/ir/flush.txt` の並びをそのまま出す。
`rmtSetCarrier` の第3引数は IDF の `polarity_active_low` に直結しているので **false**(true だと待機中にキャリアが出っぱなしになり、受信側が飽和して届かない)。
IRremoteESP8266 は Arduino コア 3.x でビルドできないため使っていない。
